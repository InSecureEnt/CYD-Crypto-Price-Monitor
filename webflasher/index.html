CYD Crypto Ticker

Shows live Bitcoin and Monero prices on an ESP32-2432S028 ("Cheap Yellow Display"). Tap the screen to refresh prices, or triple-tap it to see today's weather (°F) for your ZIP code.

Your browser doesn't support web flashing. Use Chrome or Edge on a desktop computer. Web flashing requires HTTPS.

How to use

  1. Plug the board into your computer with a USB data cable.
  2. Click Install above, choose the board's serial port, and confirm.
  3. When flashing finishes, the screen shows a CYD-Ticker-Setup WiFi hotspot.
  4. On your phone, join that hotspot, pick your home WiFi (2.4 GHz), enter your US ZIP code (used for the weather page) and save.
  5. Prices appear within a few seconds. Tap to refresh, triple-tap for the weather page, tap again to go back.

To change the saved WiFi or ZIP code later, hold the screen while powering on the board until it says "WiFi settings cleared".

No port listed on Windows? Install the CH340 USB driver. Still stuck? Try another cable, since some only charge.
