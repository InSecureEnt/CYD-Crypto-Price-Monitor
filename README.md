Designed for 2.8" CYD 
CYD boards (especially the ones with both USB-C and micro-USB ports) use an ST7789 display instead of the ILI9341
The board must be an ESP32-2432S028 with the ST7789 display,
Windows users may need the CH340 driver if no port appears.
Webflasher is available at https://insecureent.github.io/CYD-Crypto-Price-Monitor/webflasher/
